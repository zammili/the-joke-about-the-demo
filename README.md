A one-joke program for make.fun's **The joke about the demo** bounty.
`main.py` (Python 3.13, no network, no dependencies) writes a single
one-line joke about working beside AI coding agents to
`/output/entry.txt` — between 1 and 280 characters of UTF-8, and
nothing else in the file.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

## Layout

- `main.py` — the whole entry: the joke, and the write to
  `/output/entry.txt`.
